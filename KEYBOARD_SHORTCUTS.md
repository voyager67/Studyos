# StudyOS Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + K` on Windows/Linux or `⌘ + K` on macOS | Open Quick Find. |
| `/` when focus is not in a text field | Open Quick Find. |
| `Enter` while Quick Find is open with a result selected | Open the first matching result. |
| `Esc` | Close Quick Find or an open StudyOS dialog. |
| `N` when not typing | Open a new task; in Notes vault, create a new note. |
| `Tab` / `Shift + Tab` | Move through controls. |
| `Enter` or `Space` on a button | Activate the focused control using standard browser behaviour. |

Shortcuts are intentionally disabled while the user is typing in an input, textarea, select, or editable surface. Browser and assistive-technology shortcuts may take precedence.
